# 開発ログ

## 2026-09-06 面ハンドルでのリサイズ

### 実装した内容

- Rキー／ツールバーボタンで切り替えるリサイズモードを追加。選択パーツのローカル6面中央へ軸色の立方体ハンドルを置き、距離に応じて内部解像度上約6pxへ拡縮し、深度判定なしで前面描画する。
- ドラッグ平面はローカル面法線軸を含み、カメラ方向へ最も正対する向きから算出。軸成分だけをグリッドスナップし、箱はサイズと中心、円柱は高さと中心または半径をプレビューする。最小寸法1でクランプする。
- pointerup時のみ、変更された全プロパティを1件の `setTransform` で確定する。ドラッグ中のOrbitControls停止、クリック選択抑止、再構築・数値入力後のハンドル追従も同じ経路へ統合した。

### 詰まった点

- 片面を1単位動かすと幾何学上の中心は0.5単位移動する一方、ModelDocは位置を整数に限定している。既存形式を壊さないため、ローカル軸方向の中心移動をワールド座標へ変換後、各成分を整数へ丸めて保存する方針とした。
- OrbitControlsより前にハンドル操作を受け取る必要があるため、キャプチャフェーズでハンドルを判定し、掴めた場合だけイベント伝播を止めた。

## 2026-09-06 回転ギズモ

### 実装した内容

- TransformControls に15度スナップの回転モードを追加し、W（移動）／E（回転）のキーとツールバーボタンで切り替えられるようにした。入力欄へフォーカス中はキー操作を無効化し、選択中のモードをボタンに表示する。
- 回転中はメッシュと右パネルだけをプレビューし、ドラッグ終了時に角度を整数へ丸めて0〜359度へ正規化する。値が変わった場合だけ `setTransform` を1回発行するため、1ドラッグが1件のUndo履歴になる。
- 既存のシーン再構築、再attach、OrbitControls無効化、クリック選択抑止の経路を移動・回転で共用した。パネル編集後の再構築でもギズモのモードと姿勢が保たれる。

### 確認

- JavaScript構文、W／E切替、入力中のショートカット抑止、15度スナップ、回転の整数化・正規化、単一コマンド確定と同値時の抑止を確認。
- 実ブラウザ確認も試みたが、実行環境でローカルサーバーのポート待受が拒否され、ブラウザ連携面もなかったため未実施。

## 2026-09-06 移動ギズモ

### 実装した内容

- Three.js r169 の TransformControls を移動モードで追加し、1グリッド単位のスナップ、選択への attach／選択解除時の detach を実装。
- ドラッグ中はメッシュだけをプレビューし、右パネルの位置をリアルタイム更新。ドラッグ終了時に整数へ丸め、位置が変わった場合だけ `setTransform` を1回発行するため、Undo履歴は1操作につき1件となる。
- ギズモ操作中は OrbitControls を無効化し、ギズモの pointerup が既存のクリック選択へ流れないようにした。TransformControls の `change` でもイベント駆動描画を更新する。
- ModelDoc からのシーン再構築後は、選択中の新しいメッシュへギズモを再 attach する。右パネルでの位置変更も同じ再構築経路を通るためギズモが追従する。

### 詰まった点

- r169 の TransformControls は Object3D ではないため `getHelper()` をシーンへ追加する必要があった。また再構築時に helper のGPU資源まで破棄しないよう、旧シーンから外してから既存資源を dispose する構成にした。
- TransformControls は既存の選択判定より先に pointerdown を受け取るため、`dragging` を見てギズモ操作をクリック候補へ登録しないことで誤選択を防いだ。

### 確認

- JavaScript構文、ドラッグ確定時の単一コマンド化、整数丸め、同位置でのコマンド抑止、再構築後の再 attach を確認。
- 実ブラウザ確認も試みたが、実行環境でローカルサーバーのポート待受が拒否され、利用可能なブラウザもなかったため未実施。

## 2026-09-06 プロトタイプ第一版

### 実装した内容

- ビルド不要の ES Modules と Three.js で、日本語UI、人型サンプル、箱・円柱の追加／削除、選択、整数値・色の編集を実装。
- ModelDoc とコマンドを軸に Undo/Redo、JSON保存・読込を実装。
- 384×216 の固定描画と整数倍拡大、3段階トゥーンを実装。
- アウトラインをクリップ空間での押し出しに変更。内部解像度で通常1px、選択時は黄色2pxとし、幅・解像度・色を uniform 化。BackSide と深度書き込みを維持した。
- サンプルの脚を x=±2、腕を x=±4 に変更し、寸法を保って隙間を確保。初期カメラを (24,20,30) から (18,16,23) に寄せた。

### 詰まった点

- ワールドスケール拡大による輪郭はカメラ距離に左右され、低解像度ではほぼ見えなかった。画面上のピクセル幅で押し出す方式に置き換え、ゼロ方向の法線は正規化を避けた。
- サンプルの左右の脚が密着し、一塊に見えていたため配置を調整した。

### 確認

- 変更したJavaScriptの構文、サンプル座標、JSON往復、距離を変えた1px／2pxの押し出し計算を確認。初期カメラで人型の全頂点が画角内に収まり、投影高は約154pxとなる。
- 実ブラウザでの描画確認は未実施。実行環境でサーバーのポート待受が拒否され、利用可能なブラウザもなかった。
