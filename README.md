# つみきモデラー

箱と円柱を組み合わせる、ドット絵テイストの3Dモデラーのプロトタイプです。日本語UI、ビルド不要のHTMLとES Modulesで動作します。

## 起動

このディレクトリで以下を実行し、 http://localhost:8000/ を開きます。

```sh
python3 -m http.server 8000
```

Three.js 0.169.0をCDNから読み込むため、インターネット接続とWebGL対応ブラウザが必要です。GitHub Pagesにはファイルをそのまま配置できます。

## 実装範囲

- 人型サンプル、箱・円柱の追加と削除、一覧／クリック選択
- 名前・整数の位置／寸法／回転（度）・色の編集、固定パレット
- Undo/Redo、JSON保存・読込（読込成功時に履歴をリセット）
- 384×216固定描画、整数倍拡大、3段階トゥーン、逆押し出しアウトライン
- 寸法比例（既定4px/グリッド）の箱・円柱UV、ピクセルテクスチャ、UV展開図プレビュー
- ドラッグで回転、ホイールでズーム、右ドラッグでパン
- `?bridge=1` で有効になるMCPブリッジ（モデル取得・コマンド適用・検証・384×216 PNGプレビュー）

画面が384×216より狭い場合は1倍を維持し、スクロール表示します。座標・回転は±10000、寸法は1〜10000、円柱の分割数は3〜64、最大1000パーツです。小数や不正なJSONは受け付けません。自動保存はありません。作品はJSON保存してください。

ModelDocを唯一のモデル状態とし、`applyCommand(doc, cmd)`は入力を変更せず新しいドキュメントを返します。コマンドは`addPart`（part）、`removePart`（partId）、`setTransform`（partId, transform）、`setColor`（partId, color）、`rename`（partId, name）。シーンは毎回再構築します。

MCPサーバーの導入方法は [mcp/README.md](mcp/README.md) を参照してください。glTF出力は未実装です。
